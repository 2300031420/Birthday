# 🎀 Gen Z Birthday Website

A pink, glittery, heart-filled birthday website template for the people you love the most. 💖

Built with bows, disco balls, photo memories, cute animations, and just the right amount of emotional damage.

## 🌐 Live Demo

👉 https://birthday-website-template-rqxnent5m.vercel.app/

## ✨ Features

* 🔍 Interactive birthday search experience
* 🎀 Coquette / Pinterest-inspired aesthetic
* 🪩 Floating disco balls, hearts, bows, and sparkles
* 📸 Memory photo gallery
* 💌 Personalized birthday message section
* 🎂 Celebration finale
* ⚡ Smooth animations with Framer Motion
* 🎨 Easy customization for your special person

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/harshitagawas/birthday-website-template
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Visit:

```text
http://localhost:3000
```

## 💖 Customization
